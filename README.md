# Zomato Restaurant Analytics using Tableau

## 📌 Project Overview

This project analyzes restaurant data using Tableau to understand
restaurant performance, ratings, pricing, cuisines and city-level trends.

An interactive Tableau dashboard was developed to transform restaurant
data into meaningful business insights and support location and
restaurant-level analysis.
## 🔗 Tableau Public Dashboard

👉 **[View Interactive Zomato Tableau Dashboard](https://public.tableau.com/app/profile/bansi.hadiyal/viz/Zomato_17505156286900/Dashboard1)**

---

## 🎯 Business Objective

The objective of this project is to analyze restaurant performance
across different cities and identify patterns in:

- Restaurant distribution
- Average ratings
- Restaurant pricing
- Restaurant branches
- Restaurant reach across cities
- Top-rated restaurants
- Restaurant and city-level performance

## 🔍 Analysis Performed

The project includes analysis of:

1. Number of restaurants by city
2. Average restaurant rating by city
3. Average restaurant cost by city
4. Number of branches for each restaurant
5. Top 10 restaurants based on city reach
6. Top 5 restaurants based on average rating
7. Restaurant performance based on minimum rating-count criteria
8. Total restaurants
9. Average cost
10. Average rating
11. Total votes
12. Additional restaurant performance insights

## 💡 Business Questions

The dashboard helps answer questions such as:

- Which cities have the highest number of restaurants?
- Which cities have the highest average restaurant ratings?
- How does restaurant cost vary across cities?
- Which restaurants have the highest number of branches?
- Which restaurants have the widest presence across cities?
- Which restaurants have the highest average ratings?
- How do restaurant ratings and costs vary by city?

---

## 📊 Dashboard Interactivity

The dashboard includes:

- City-level filtering
- Interactive dashboard actions
- Dynamic restaurant analysis
- KPI-based performance overview

Users can select a city and interact with the dashboard to explore
restaurant performance at a more detailed level.
